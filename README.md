# **Sreenikethan Iyer - Portfolio Website**

Welcome to the repository for my personal portfolio website! This site showcases my projects, experience, education, and skills as a newly graduated Computer Science Engineering student, seeking a Software Development (SDE) role.

## Tech Stack

| Technology       | Purpose                                       |
| :--------------- | :-------------------------------------------- |
| **Astro**        | Core framework & Static Site Generation (SSG) |
| **Tailwind CSS** | Styling                                       |
| **Vite**         | Build tool and bundler                        |
| **GitHub Pages** | Hosting & deployment                          |

## Getting Started

To run this project locally, run these commands:

```bash
git clone https://github.com/SreenikethanI/sreenikethani.github.io.git
cd sreenikethani.github.io

npm install

npm run dev
```

The site will be available at `http://localhost:4321`.
